# blender-blur-faces
A blender add-on to blur faces in a video

# INSTALLATION
Clone the repo

Then open blender
Edit -> Preference -> Add-ons
Click the drop-box in the upper right corner -> Install from disk
Locate face_blur_workflow.py and select that

# Use
Open blender to VFX mode

Select the Face Blur verticle tab (center screen, slightly to the right)
Follow the tab linearly.
